# Using AI as a catalyst for interprofessional learning

This repository hosts the self-contained, offline-first interactive module for the FAIMER Group 2 November 2026 mentored learning web session.

## Use

Open the published site in a modern browser. Work is stored only in that browser until the learner downloads their record. The certificate PDF is unlocked after the required learning evidence and facilitator verification fields are complete.

## Privacy

Do not enter patient details, personal contact details, or restricted workplace information. The certificate name is kept in the browser unless the learner downloads or prints the certificate.

## Boundary

This educational module does not provide clinical advice. Institutional AI, privacy, academic integrity, and data-retention policies remain authoritative.
